# 🌟 Highlighted Projects

## 🌱 Environmental Awareness → Sustainability Tracking Platform

**Solution:** Cleanlyfe

A sustainability-focused web application that calculates users' carbon and water footprints through personalized questionnaires. The platform helps users understand their environmental impact and encourages more sustainable habits through actionable insights and environmental metrics.

**Technologies:** HTML, CSS, JavaScript, Bootstrap, MySQL

---

## 🚰 Water Waste Reduction → IoT Smart Water Management System

**Solution:** WaterFlow

An IoT-powered platform connected to a custom ESP32 device installed on household water valves. The application enables remote control, scheduled water shutoffs, and automatic closures based on temperature conditions. WaterFlow integrates with Cleanlyfe to promote responsible water consumption and resource management.

**Technologies:** React Native, Expo, NativeWind, ESP32

---

## 🌤️ Weather Information Access → Interactive Forecast Dashboard

**Solution:** Wind-Wise

A complete weather web application featuring real-time weather visualization, interactive maps, and a forecasting dashboard. Users can explore weather conditions, geographic data, and forecasts through an intuitive and responsive interface.

**Technologies:** JavaScript, HTML, TailwindCSS, MapBox API, OpenWeatherMap API

---

## 🏋️ Gym Operations Management → Comprehensive ERP Platform

**Solution:** GYMERP

A full-featured ERP system for gym administration where I contributed to backend development. The platform includes inventory management, membership administration, payment processing, attendance tracking, user management, and operational reporting tools.

**Technologies:** TypeScript, C#, .NET 10, React, TailwindCSS, PostgreSQL

---

## 💕 Long-Distance Relationship Organization → Private Couple Ecosystem

**Solution:** NearU

A mobile-first web application designed for couples. The platform includes shared journals, notes, mood tracking, anniversaries, relationship milestones, a turn-based drawing game inspired by Pinturillo, and location-sharing features that allow both partners to stay connected through a single private ecosystem.

**Technologies:** React, TailwindCSS, DaisyUI, Supabase, PostgreSQL
